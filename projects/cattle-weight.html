Ongoing MSc thesis

Image-based live weight estimation of cattle in Bangladesh

A comparison of deep learning and machine learning models. The thesis is being written now, so this page shows the question and the method. Results will be added after the thesis defence.

StatusOngoing, expected November 2026

The question

Live weight guides feeding, treatment and sale, but on most farms and markets in Bangladesh it is judged by eye, because scales are costly and hard to move. I ask whether ordinary photographs could stand in for the scale, and which kind of model reads them best.

Why the test design matters

Each cow in the CID has four photos. If photos are split into training and test sets at random, the same cow can sit on both sides, and the model is tested on animals it has already seen. Earlier work on this dataset did not say how photos were split, and the dataset authors' public code splits single images at random. In my thesis every model is tested only on animals it has never seen.

Method

Three kinds of model, one fair test

  • Baseline: linear regression on height and breed, no photo at all. Every other model has to beat it.
  • Classical machine learning: YOLO11 cuts the cow out of each photo, its outline is measured, and linear regression, SVR, random forest and gradient boosting predict weight from those measurements.
  • Deep learning: nine ImageNet-pretrained networks read the photo directly. Seven are CNNs (ConvNeXt-Tiny, DenseNet121, EfficientNet-B0 and B3, MobileNetV3, RegNetY, ResNet50) and two are vision transformers (Swin-Tiny, DeiT-Small). I also rebuilt the small CNN from an earlier study on the same data.

How models are scored

  • Five folds, built from animals, stratified by weight class.
  • All four photos of a cow stay in the same fold.
  • Each animal's four photo estimates are averaged, then compared with its real weight.
  • Error is reported in kg and in percent, by weight class and by breed, with bootstrap intervals and paired tests between models.

A look at the code

Excerpts from my Kaggle training notebook, copied as they are. The full code will be published with the thesis.

Folds are built on animals, not photos, and the no-photo baseline is fitted on exactly the same folds.

from sklearn.model_selection import StratifiedKFold
from sklearn.linear_model import LinearRegression

df["weight_class"] = pd.cut(df["weight_in_kg"], [0, 200, 250, 300, 400, 10000], labels=False)
df["fold"] = -1
splitter = StratifiedKFold(n_splits=5, shuffle=True, random_state=42)
for k, (_, test_rows) in enumerate(splitter.split(df, df["weight_class"])):
    df.loc[test_rows, "fold"] = k


X = pd.get_dummies(df[["height_in_inch", "breed"]], dtype=float)
y = df["weight_in_kg"]
guess = pd.Series(0.0, index=df.index)
for k in range(5):
    test = df["fold"] == k
    guess[test] = LinearRegression().fit(X[~test], y[~test]).predict(X[test])
