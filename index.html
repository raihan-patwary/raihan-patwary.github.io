Animal science · Computer vision · Machine learning

Md Raihan Patwary

An animal scientist who builds and tests models for livestock and insect data.

I trained in animal nutrition: feeding trials, insect rearing and feed analysis. I taught myself Python, machine learning and computer vision, and now use them to estimate things farms need to know, such as how heavy an animal is, from photos and records. Every model I build is tested on animals, pens or batches it has never seen, and the code is public.

How I work

Check the data, then test honestly

Audit the data first

Before any model, I recompute what a dataset claims. In the broiler workbook, 14 of 120 pen-weeks had gains that contradict the weights.

Test on unseen units

A model is scored only on animals, pens or rearing batches it never saw in training, because that is what a farm will ask of it.

Show the work

Code, figures and checks are public on GitHub and Kaggle, so anyone can rerun them and find my mistakes.
