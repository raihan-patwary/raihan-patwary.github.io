# raihan-patwary.github.io

Personal research portfolio of **Md Raihan Patwary**, MSc researcher in Animal Nutrition at Bangladesh Agricultural University.

Live site: https://raihan-patwary.github.io

- Plain HTML, one stylesheet (`assets/css/style.css`) and one small script (`assets/js/site.js`). No frameworks, no build step on GitHub.
- Every page works without JavaScript; the script adds the menu, theme switch, figure viewer, code tabs, project filter and two small demos.
- Project code lives in its own repositories, such as [LarvaLens](https://github.com/raihan-patwary/larvalens) and [broiler-cricket-meal-analysis](https://github.com/raihan-patwary/broiler-cricket-meal-analysis).

Figures from LarvaLens use the black soldier fly larvae dataset of Geissmann (2024), CC BY 4.0. The StatQuest-style doodle on the About page is an original drawing.
